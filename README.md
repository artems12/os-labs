# Лабораторная работа №1

## Инструкция по сборке и запуску

### 1. Сборка проекта
Для компиляции программ выполните в терминале:
```bash
make
```

### 2. Запуск программы
Запустите родительский процесс:
```bash
./parent
```

### 3. Использование
1. Первой строкой введите имя выходного файла (например, `output.txt`) и нажмите `Enter`.
2. Вводите строки с целыми числами через пробел, нажимая `Enter` после каждой строки.
3. Для завершения ввода нажмите `Ctrl + D`.

### 4. Очистка скомпилированных файлов
```bash
make clean
```
